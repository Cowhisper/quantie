# 深度学习股票日线行情预测

日期说明：
信号日：取信号的当天
预测日：信号日的下一天

涨跌幅定义：
(预测日收盘价 - 信号日收盘价) / 信号日收盘价

## 输入
网络输入维度 B×T×C，其中
- B 代表 batchsize
- T 代表 一个连续时间段，取从信号日之前的 30 天，包含信号日
- C 代表 输入股票特征维度

其中 C 由几段特征拼接而成
 1. 一年中的相对时间，信号日日期在一年中的相对位置，归一化到[-1, 1]
 2. 行业特征，枚举行业值 S，维护行业特征 Embedding，参与学习
 3. 信号日行情特征，如归一化后的开盘，收盘价，交易量，换手率等，指标都需要归一化处理
    - 价格归一化：按时间段 T 内价格的最大/最小值归一化到[-1, 1]
    - 交易量归一化：按时间段 T 内交易量的最大/最小值归一化到[-1, 1]
    - 换手率：归一化到[-1, 1]


## 输出
网络的输出维度 B×1，其中
- B 代表 batchsize
- 维度 1 代表预测日标签的 logits

## 监督方式
学习任务为分类任务 + 回归任务，其中
- 分类任务以 softmax + cross entropy loss 监督，预测日标签为：
  - 近乎跌停，当日涨跌幅(-20%~-15%)
  - 大跌，当日涨跌幅(-15%~-10%)
  - 跌，当日涨跌幅(-10%~-3%)
  - 波动，当日涨跌幅(-3%~+3%)
  - 涨，当日涨跌幅(+3%~+10%)
  - 大涨，当日涨跌幅(+10%~15%)
  - 近乎涨停，当日涨跌幅(+15%~20%)
- 回归任务以smooth-l1 loss 监督，GT 为预测日涨跌幅[-20%, 20%]归一化到 [-1, 1]


## 网络架构
 Transformer 架构的网络，无需太大


## 数据来源
参考 `a_stock_daily.db`


## 代码架构
```
--dl
  |-data_preprocess.py (数据预处理脚本，从`a_stock_daily.db`格式转化成，训练格式的数据)
  |-data.py (基于 pytorch 实现 dataset, 包含异常数据处理)
  |-net.py (上述网络结构)
  |-train.py (训练脚本, 日志写入 dl/checkpoints/train.log)
  |-eval.py (评估脚本, 输出所有标签类别的 precision/recall, 日志写入 eval.log)
  |-predict.py (预测脚本, 以最近 seq_len 日行情预测下一交易日涨跌标签, 输出 CSV，包含涨跌幅，预测标签，以及各个标签的预测概率)
```
