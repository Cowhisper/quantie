# 策略描述

Gianluca Bruni，意大利西西里人，现居迪拜，交易约五年，主做外汇与指数
（prop firm 资金账户，Morpheus Education 创始人）。他把自己定义为
price action 交易员：不依赖指标，只读 K 线本身与供需区域（supply &
demand zones），核心工具是**亚盘箱体（Asian Session Box）**——亚洲时段
（东京盘）波动率低，价格收敛出一个窄幅震荡箱体；欧洲时段（伦敦盘）
开盘后流动性涌入，价格放量突破箱体，沿突破方向跟进。其方法自称
"99% 机械化"：每个形态（schematic）的入场/不入场条件都是客观规则
（"If X, I go in. If Y, I don't go in. The end."），并用约两年历史数据
回测每个形态的统计表现，**按星期几调整风险敞口**（如统计显示周三对
某个形态不利，则周三降低该形态的风险）。风控信条：再好的策略也救不了
情绪化交易，纪律与耐心优先。

原策略机械流程（外汇/指数，日内）：
1. **画箱体**：亚盘时段（约 00:00–08:00 UTC）的高低点构成箱体上下沿；
   箱体必须足够窄（低波动收敛），宽箱体没有突破价值。
2. **等突破**：伦敦开盘后价格放量突破箱体上/下沿。关键区分
   **accepted expansion（被接受的扩张）**与 **rejected break（被拒绝的
   假突破）**——突破后价格站稳箱体之外（收于箱体外、回踩不破）才算
   接受，快速跌回箱体内则是拒绝，不做或反手。
3. **入场与止损**：突破确认后跟进；止损放在箱体中点或箱体对侧
   （给价格留出呼吸空间，箱体越宽止损越远、仓位越小）。
4. **目标位**：按箱体高度向上/下投影（度量目标），或固定盈亏比
   （常用 1:2）；每天最多一笔，达到日亏损上限即停手。
5. **星期过滤**：按历史统计对特定星期几的形态降低风险或不做。

本仓库的 A 股日线近似（与 strategy_ross_cameron.py 同一套无未来函数约定）：
- 原策略为外汇/指数日内交易（亚盘箱体 + 伦敦突破），A 股无盘中分时
  数据，把「亚盘箱体」近似为**过去 N 个交易日的窄幅横盘区间**
  （日线级别的低波动收敛，与 Darvas 箱体思想同源），把「伦敦开盘放量
  突破」近似为**信号日收盘站上箱体上沿且相对放量**——收盘确认接受、
  次日开盘成交，避免前视偏差（A 股 T+1 下买入当日也不可卖出）。
- 「accepted vs rejected」机械化为：收盘价必须收在箱体上沿之外
  （盘中插破不算），且收盘位于当日振幅上半部（上影线过长=突破被拒绝
  的抛压特征）；买入后跌回箱体内部（收盘 < 箱体上沿）即判定突破失败
  离场（仅持仓初期检查，走远后参考线失效，交给止损/移动止盈）。
- 「按星期调整风险」机械化为 `skip_weekdays` 黑名单（默认空）：命中
  统计上不利的星期几则该日信号不入场；A 股是否有效需自行回测标定，
  默认不过滤。
- 止损/仓位改为仓库统一约定：固定本金仓位（无法表达"箱体越宽止损
  越远、仓位越小"的倒推，见「买入量」），固定百分比止损 + 突破失败
  退出 + 移动止盈 + 固定止盈（度量目标/固定盈亏比的日线近似）+
  时间止损。
- A 股专属约束沿用仓库实证结论：排除 ST/*ST；信号日换手率上限
  （高换手=拥挤交易）、涨幅上限（不追涨停延续）、次日开盘追价上下限
  （高开不追、低开动能证伪放弃）。

## 买入

### 买入倾向排序
策略逐股扫描信号，不感知账户状态；所有股票的买入信号汇总到账户层
（`lib/account.py` 的 `simulate_account`），在资金与持仓上限
（`engine.max_positions`，默认 10 只）约束下按评分降序成交——评分高
（最可能赚钱）的信号优先获得资金与仓位，评分相同按股票代码排序保证
确定性。
- 排序公式：`score` = 4 因子加权，全部因子与箱体突破的 edge 逻辑对齐
  （箱体越窄/突破量越足/收盘越强势/突破越新鲜，排序越靠前）：
  `score = 0.30·t_箱体 + 0.30·t_放量 + 0.20·t_收盘 + 0.20·t_新鲜`
  - `t_箱体 = 1 − clip(箱体宽度 / max_box_width_pct, 0, 1)`：箱体越窄
    评分越高（亚盘收敛越充分，突破后的度量空间越干净）
  - `t_放量 = clip((相对放量倍数 / breakout_vol_mult − 1) / 2, 0, 1)`：
    突破日相对放量越足评分越高（流动性涌入=机构接受突破的代理，
    刚到阈值 0 分，3 倍阈值以上 1 分）
  - `t_收盘 = clip((收盘 − 最低) / (最高 − 最低), 0, 1)`：收盘越贴近
    当日最高评分越高（accepted expansion：买盘持续到收盘；长上影=
    rejected break 的抛压特征）
  - `t_新鲜 = 1 − clip((收盘/箱体上沿 − 1) / 0.05, 0, 1)`：收盘刚站上
    箱体上沿（未过度延伸）评分越高——突破当日已远离箱体的信号，
    次日入场价盈亏比恶化
  - 写入 `Trade.score`。权重为初版默认值；校准中按信号特征分桶收益
    标定的 v2（温和放量反向计分 + 收盘 0.85 封顶 + 52 周高位因子）
    反而打乱账户层资金分配（收益 −9.0pp），已证伪回滚，v1 保留
    （见文末「A 股实证校准记录」）。
- 超参注释（全部可在配置段 `GianlucaAsianBoxStrategy` 调整；A 股初版
  默认，标注「原文」者为公开资料直接迁移）：
  - 箱体：`box_window`=20（箱体回看窗口，约一个交易月——亚盘时段约
    8 小时的日线代理；原文箱体为当日亚盘高低点）；`max_box_width_pct`=
    0.15（箱体宽度上限 = 箱体上沿/下沿 − 1 ≤ 15%——原文「箱体必须足够
    窄」的量化：低波动收敛才有突破价值，宽箱体=已经走过行情，突破
    空间被透支）
  - 突破确认：`breakout_vol_mult`=1.5（突破日成交量 ≥ 过去 `vol_window`
    =20 日均量 × 1.5——原文「伦敦开盘流动性涌入」的代理：无量突破
    多为假突破）；`min_close_pos`=0.5（信号日收盘位于当日振幅上半部——
    accepted expansion 与 rejected break 的区分：收在下半部=突破被
    抛压拒绝）
  - 质量过滤（仓库实证沿用）：`max_turn_pct`=10（信号日换手率上限 %，
    高换手=拥挤交易，次日退潮概率大；A 股校准 15→10：turn(10,15] 分桶
    107 笔均 −0.61% 胜率 29.9% 全场最差）；`max_signal_pct`=9（信号日
    涨幅上限 %，不追涨停/接近涨停的延续，动能透支）
  - 排雷：`skip_st`=true（排除 ST/*ST，退市风险不符合突破前提）
  - 星期风险调整：`skip_weekdays`=[1]（不入场买入的星期几列表，0=周一
    …4=周五——原文「按星期几统计调整风险」的机械化；A 股校准：信号日
    周二 180 笔均 −1.15% 胜率 27.2% 显著最差（=买入日周三，与原文
    「周三不利」口径一致），故默认周二不入场；加砍周四胜率升收益降，
    已证伪）
  - 追价保护：`max_chase_pct`=0.03 / `min_chase_pct`=−0.03（次日开盘
    相对信号日收盘高开超 3% 放弃——不追高，A 股校准 5%→3%：
    chase(3%,5%] 分桶 8 笔均 −4.93% 胜率 12.5% 极差；低开超 3% 同样
    放弃——突破隔夜即退潮、动能证伪，仓库统一约定）
- 最低买入要求：信号日同时满足——
  ① 箱体：过去 `box_window` 日（不含当日）最高价/最低价 − 1 ≤
     `max_box_width_pct`；
  ② 突破：收盘价 > 箱体上沿（盘中插破不算，须收盘确认）；
  ③ 放量：当日量 ≥ `vol_window` 日均量 × `breakout_vol_mult`；
  ④ 接受：收盘位于当日振幅上半部（(close−low)/(high−low) ≥
     `min_close_pos`，一字零振幅不产生信号）；
  ⑤ 质量：换手率 ≤ `max_turn_pct`、涨幅 ≤ `max_signal_pct`；
  ⑥ 非 ST/*ST（skip_st）、信号日星期几不在 `skip_weekdays` 内、
     信号日处于回测区间内、命中全部附加市场过滤条件（`conditions`，
     如价格区间）、固定本金按次日开盘价能买入至少 1 手；
  低于任一要求不触发买入。次日开盘高开超过 `max_chase_pct`（默认 3%）
  或低开超过 `min_chase_pct`（默认 −3%）均放弃。
  满足要求的信号也不保证成交：当日资金或持仓不足时，低分信号被跳过
  （整笔作废）。
- 数据要求：箱体与均量窗口需要信号日前约 `box_window + vol_window + 1`
  个交易日（默认约 41 天）的历史数据，`warmup` ≥ 60 即可，仓库默认
  回测 warmup=250 / 预测 warmup=120 均满足。

### 买入量
固定本金仓位（`lib/position.py` 的 `FixedCapitalPosition`）：
买入股数 = `capital` // 次日开盘价，向下取整到整手（`lot_size`，默认
100 股/手）；不足 1 手放弃本次买入。本金与手数可在配置段
`FixedCapitalPosition` 调整。
（原文按「止损距离倒推仓位」——箱体越宽止损越远、单笔仓位越小，
固定本金模型无法表达，以统一约定替代：宽箱体信号同样买固定股数，
但其止损距离更远、风险敞口更大，属已知近似；`max_box_width_pct`
上限间接控制了止损距离的极端情形。）

## 卖出

### 卖出条件
持仓次日起每日收盘依次检查（A 股 T+1：买入当日不可卖出），满足任一
条件即卖出：
- **止损**：收盘价跌破买入价的 (1 − `stop_loss_pct`)（默认 8%）——
  原文「止损放箱体中点/对侧」的日线近似：固定本金模型下止损距离
  与仓位不联动，取固定百分比兜底
- **突破失败（rejected break）**：收盘价跌回箱体内部（收盘 < 信号日
  箱体上沿）——原文核心判据：突破未被接受、价格重回区间即离场；
  仅持仓前 `breakout_exit_days` 个交易日检查（默认 2：突破初段跌回
  箱体=假突破；走远后该参考线失去意义，交给止损/移动止盈/止盈）
- **移动止盈**：曾盈利（持仓期最高价 > 买入价 × (1 + `trail_activate_pct`)，
  默认 3% 启动门槛——峰值仅略高于买入价时回撤 6% 等于变相止损，
  A 股校准新增；5% 门槛已证伪）后，收盘价自最高价回撤超过
  `trail_pct`（默认 6%）——动能衰减离场（突破延续失败的日线代理）
- **止盈（度量目标）**：收盘价 ≥ 买入价 × (1 + `take_profit_pct`)
  （默认 15%）——原文「按箱体高度投影目标位 / 固定盈亏比（常用
  1:2）」的机械近似：15% 约为默认箱体宽度上限（15%）的 1 倍投影、
  相对 8% 止损约 1:2 盈亏比
- **时间止损**：持仓满 `max_hold_days` 天（默认 10 个交易日）——
  原文为日内交易（当天平仓），A 股 T+1 下以短持仓周期代理其
  日内纪律：突破动能通常在数日内兑现或证伪
- 回测区间结束：日期到达 `end_time` 或最后一条数据，按当日收盘
  强制平仓

### 卖出量
全部卖出（卖出数量 = 买入数量，见 `FixedCapitalPosition.sell_amount`）。

# A 股实证校准记录

2026-11-24，`exp/baseline.yaml`，2025-01-01~2026-11-15 全库（7549 只），
分支 `autostrategy/Exp-gianluca-20261124-202601`，逐探针明细见
`exp/experiments.tsv`。收益率优先于胜率取舍（策略为低胜率高盈亏比
动量体系）。

**baseline（初版公开口径超参）**：信号 20061 → 成交 900，胜率 34.00%，
总收益率 −15.63%。诊断：突破失败退出（rejected break）409 笔占 45%
均亏 −2.34%（胜率仅 4.9%）为最大出血点——近半入场是假突破；移动止盈
109 笔均 −2.24%（峰值刚过买入价时回撤 6% = 变相止损）；时间止损
329 笔均 +2.30% 胜率 69.3% 为最赚钱出场；止盈 27 笔均 +18.08% 100%
胜率；评分 pearson 仅 0.06 区分度弱；信号日周二 180 笔均 −1.15%
胜率 27.2% 显著最差（=买入日周三，与 Gianluca 原文「周三不利」口径
一致）。

**keep 的改动（累计 胜率 +4.8pp、收益 +42.1pp）**：
1. `skip_weekdays`=[]→[1]：信号日周二不入场（帕累托，+1.9pp/+15.4pp；
   原文星期风险调整的机械化，数据与原文口径互证）
2. `trail_activate_pct`=0.03（新增）：移动止盈 3% 启动门槛
   （+0.6pp/+2.8pp，止住变相止损）
3. `max_turn_pct` 15→10：砍掉 turn(10,15] 拥挤交易桶（+2.0pp/+21.8pp，
   最显著）
4. `max_chase_pct` 0.05→0.03：chase(3%,5%] 分桶 8 笔均 −4.93% 胜率
   12.5% 极差（+0.4pp/+2.0pp）

**最终校准超参**：信号 15218 → 成交 842，胜率 38.84%，总收益率 +26.42%。

**discard 的探针**（收益均显著变差，详见过往 tsv）：突破放量收紧 2.0
（−16.6pp，与 jlaw 结论相反——箱体突破温和放量区间 1.5~2 最优）与放宽
1.2（−18.5pp）；收盘位置 0.5→0.7（−3.9pp 信号饥饿）；箱体宽度
0.15→0.09（胜率 +1.7pp 但信号 15365→6986 资金闲置 −19.3pp）；趋势
距离过滤（距 60 日线 ≤5%，信号腰斩 −16pp）；时间止损 10→15（−20.3pp
资金周转下降）；止盈 15%→20%（−14.7pp，15% 是 A 股突破后重要利润
兑现点）；trail 6%→8%（−14.1pp 盈利单回吐）；失败判定加 1% 缓冲
（−27.6pp，跌回箱体群体胜率仅 6.5% 不容等候）；止损 8%→6%
（−11.5pp 误杀回升单）；失败检查 2→1 日（−11.9pp）；trail 门槛
3%→5%（−7.6pp）；箱体窗口 20→30（−32.1pp）；低开下限 −3%→−5%
（−5.2pp）；评分 v2（温和放量反向 + 收盘 0.85 封顶 + 52 周高位因子，
−9.0pp——分桶标定的方向性改动反而打乱账户层资金分配，v1 保留）；
skip_weekdays 加砍周四（胜率 +1.84pp 收益 −2.3pp，收益率优先弃用）。

**关键教训**：该策略信号供给充足（1.5 万信号→账户仅成交 ~850 笔，
资金利用率是瓶颈），任何进一步砍信号的过滤都必须砍掉「显著负贡献」
群体才划算（如 turn(10,15] 均 −0.61%），否则资金闲置侵蚀总收益；
