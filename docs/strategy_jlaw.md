# 策略描述

J Law，香港前中学教师，2024 年以 +353.9% 收益率夺得美国投资锦标赛（US Investing
Championship）百万美元以上股票组冠军，打破 Mark Minervini 2021 年创造的 334.8%
该组纪录；2025 年以 +252.3% 卫冕，两年复利 +1,499%（同期标普 500 约 +47%）。
其体系师承 Minervini（上过他的课），核心为 VCP（波动收缩形态）突破，并发展出
自命名的 "Multiple Edge Trading System"：只在多重独立买入理由重合于同一价位时
进场。其公开统计：胜率约 45%~50%，盈利单平均 +10% 以上，亏损单平均仅 −4%~−5%
（盈亏比约 2.5~3，期望值为正的关键），年交易约 200 笔。

原策略五步流程（美股，日内到波段持仓）：
1. **选股（趋势过滤）**：股价处于 Stage 2 上升趋势——收盘价在 50 日线上方，
   50 日线在 200 日线上方，且两条均线均向上走（Trend Template 简化版）；
   流动性过滤看美元成交额（通常 >1 亿美元/日）。
2. **催化剂与动能爆发**：每段趋势背后要有基本面驱动（财报超预期、上调指引、
   新品发布），并表现为放量急涨（momentum move，大盘股一个月内 +14% 即算强，
   小盘股可能单日 +25%；偏好 2~3 天持续放量而非单日脉冲，因为机构是分批建仓）。
   不在爆发日追买——刚急涨的股票没有低风险买点，等回调。
3. **形态（VCP 波动收缩）**：上升趋势中横盘整理，回调一波比一波浅
   （如 −21.5% → −13.7% → −3.4%），且最后一次回调成交量显著萎缩（抛压耗尽）。
   整理区间最高价为突破点 Pivot。
4. **择买点（多重优势区域）**：两个买点——①激进者等放量突破 Pivot 买入；
   ②稳健者（J Law 现主要用法）等首次缩量回调至「前高阻力转支撑 + 10/20 日均线
   带 + 趋势线」重合的多重优势区域再买。均线视为一个区域而非一条线
   （20 日 EMA 与 20 日 SMA 之间的带状区）；大盘下跌日单日插穿不算破坏。
5. **止损与仓位**：止损设在形态失效处（突破买法放在整理区间最低点下方，
   回踩买法放在多重优势区域下方），幅度 3%~5%（有时 2%）；单笔风险控制在
   账户总额的 ~0.35%（千分之三左右），用倒推法算股数（风险额 ÷ 每股风险）。
   止损越宽仓位越小，止损越窄仓位可以越大。

卖出分三种模式（J Law 按股票类型匹配，不用单一规则）：
- **趁强卖**（Sell into strength）：涨至阻力位或风险收益比达 2~2.5 倍时分批止盈；
  对生意模式确信度越高卖得越少。
- **趁弱卖**（Sell into weakness）：纯动量股（无成熟业务支撑）跌破 10 日/20 日均线
  （留少量缓冲防插针）即离场。
- **趋势持有**（Hold the trend）：大型绩优成长股沿 10/20 日均线持有，只在
  异常行为时动作；另有「零成本减仓」法——涨幅约 70% 时卖出 ~58.8% 收回本金，
  剩余仓位相当于免费持有（只适用于十年内大概率仍在、有护城河的龙头）。
其夫人用同一套系统但只按「趁弱卖」执行，2024 年同组亚军（+273.8%）。

本仓库的 A 股日线近似（与 strategy_connors_rsi2.py 同一套无未来函数约定）：
- 信号一律由收盘数据确认、次日开盘成交；原版突破/回踩按日内分时执行，
  此处为日线近似（突破日收盘站上 Pivot、回踩日收盘回到均线带内均按收盘确认）。
- 选股第 1 步的趋势过滤、第 2 步的催化涨幅与流动性、第 3 步的 VCP 收缩与
  缩量均为日线可计算的机械近似：以「近 contraction_prior 日振幅 vs 前
  contraction_recent 日振幅逐次变浅 + 末段振幅 ≤ 上限 + 近 5 日均量 / 20 日均量
  ≤ 上限」量化波动收缩与量能枯竭；催化剂本身（财报/指引）日线无法直接获得，
  以「放量急涨 + 基底处于 52 周高位区（强势领导股）」代理（相对强度思想，
  源自 O'Neil/Weinstein）。
- 止损/仓位改为仓库统一约定：固定本金仓位（无法表达"单笔风险 0.35% 倒推股数"，
  见「买入量」），止损按「信号日算出的形态失效价」与「买入价固定百分比」二者
  孰近（ tighter ）取值，风险上限默认 5%（对应其 3%~5% 规则）。
- 卖点机械化为：跌破持仓均线带（趁弱卖）/ 固定止盈（趁强卖，默认 +20%，
  对应 Minervini 20~25% 与 R:R 2~2.5 规则的日线近似）/ 固定止损 / 时间止损。
  「趋势持有/零成本减仓」需要人工类型判断，不在机械实现内。
- A 股专属约束：排除 ST/*ST（退市风险不符合强趋势前提）；流动性以 20 日平均
  成交额（amount ≥ 1 亿元）近似其美元成交额过滤；T+1 与涨跌停沿用仓库约定。
- **注意：以下 A 股超参均为初版默认值（依据原策略公开口径直接迁移），
  尚未经过本仓库 baseline 回测校准，评分权重与阈值待 EXPERIMENTS.md 流程验证。**

## 买入

### 买入倾向排序
策略逐股扫描信号，不感知账户状态；所有股票的买入信号汇总到账户层
（`lib/account.py` 的 `simulate_account`），在资金与持仓上限（`engine.max_positions`，
默认 10 只）约束下按评分降序成交——评分高（最可能赚钱）的信号优先获得资金与仓位，
评分相同按股票代码排序保证确定性。
- 排序公式：`score` = 5 因子加权，全部因子与 J Law 的 edge 叠加逻辑对齐
  （收缩越紧/量越枯/离均线带越近/突破量越足/越接近 52 周高位，排序越靠前）：
  `score = 0.30·t_收缩 + 0.20·t_缩量 + 0.20·t_买点 + 0.15·t_高位 + 0.15·t_趋势`
  - `t_收缩 = 1 − clip(末段振幅 / max_last_contraction_pct, 0, 1)`：
    VCP 末段收缩越紧评分越高（最后一波回调越浅，抛压越接近耗尽）
  - `t_缩量 = 1 − clip(近5日均量 / 20日均量, 0, 1)`：量能越枯评分越高
    （回踩/整理时无量，说明持有人惜售）
  - `t_买点`：突破买法 = `clip((当日量/20日均量 − 1) / 2, 0, 1)`（放量越足
    机构痕迹越明显）；回踩买法 = `1 − clip(|收盘 − MA20| / (MA20 × 2%), 0, 1)`
    （收盘越贴近 20 日均线带，多重优势重合度越高）
  - `t_高位 = clip(收盘 / 250日最高收盘, 0, 1)`：越接近 52 周高位评分越高
    （领导股/相对强度，Weinstein Stage 2 强势股特征）
  - `t_趋势 = clip((收盘/MA200 − 1) / 0.50, 0, 1)`：中长期趋势越强评分越高
  - 写入 `Trade.score`。权重为初版默认值，待 baseline 校准（见策略描述末尾说明）。
- 超参注释（全部可在配置段 `JLawMultipleEdgeStrategy` 调整；A 股初版默认，
  标注「原文」者为公开资料直接迁移）：
  - 趋势模板：`trend_fast`=50 / `trend_slow`=200（原文规则：收盘 > 50 日线 >
    200 日线且两线向上；`fast_rise_days`=10 / `slow_rise_days`=20 判定"向上走"）
  - 催化与基底：`rally_window`=120、`min_rally_pct`=0.30（原文规则：先有
    一段大幅上涨，120 日内最低价到基底 Pivot 涨幅 ≥ 30%，代理 catalyst
    momentum move）；`base_window`=45（基底回看窗口，约 2 个月，VCP 基底
    通常 3 周~数月）；`max_base_depth_pct`=0.30（基底自 Pivot 的最大深度，
    深于 30% 视为非收缩型整理）
  - VCP 收缩：`contraction_recent`=10 / `contraction_prior`=20（两段对比窗口，
    近 10 日振幅 vs 其前 20 日振幅，要求逐次变浅）；`contraction_shrink`=0.6
    （近段振幅 ≤ 前段 × 0.6，原文「每次回调都要比上一次浅」的量化）；
    `max_last_contraction_pct`=0.15（末段振幅上限，原文典型案例末段仅 −3.4%）
  - 量能：`dryup_days`=5 / `dryup_ref`=20 / `volume_dry_ratio`=0.8
    （原文规则：末段回调量显著萎缩——近 5 日均量 ≤ 20 日均量 × 0.8）；
    `breakout_vol_mult`=1.5（突破买法：当日量 ≥ 20 日均量 × 1.5，原文「放量
    突破 Pivot」）；`pullback_vol_ratio`=0.8（回踩买法：当日量 ≤ 突破日量 × 0.8）
  - 买点：`entry_mode`="both"（breakout=放量突破 Pivot / pullback=回踩均线带
    多重优势区 / both=两者都要，原文两种买法并存，其本人现主要用回踩）
  - 回踩买法：`pullback_window`=10（突破后 10 日内首次回踩有效）；
    `ma_zone`=20 / `ma_zone_pct`=0.02（20 日均线带 ±2%，均线视为区域，
    对应其 20EMA~20SMA 带状区思想）
  - 流动性与排雷：`min_amount`=1e8（20 日平均成交额 ≥ 1 亿元，近似其
    >1 亿美元/日美元成交额过滤）；`skip_st`=true（排除 ST/*ST）
  - 追价保护：`max_chase_pct`=0.05（次日开盘相对信号日收盘高开超过 5% 放弃，
    仓库统一约定——VCP 突破后隔夜高开过多则盈亏比恶化）
- 最低买入要求：信号日同时满足——
  ① 趋势模板：收盘 > MA50 > MA200 且 MA50、MA200 分别近 10/20 日向上；
  ② 催化：近 120 日最低价至 Pivot 涨幅 ≥ 30%；
  ③ 基底：近 45 日自 Pivot 最大回撤 ≤ 30%，且近 10 日振幅 ≤ 15% 且
     ≤ 前 20 日振幅 × 0.6（VCP 逐次收缩）；
  ④ 量能：近 5 日均量 ≤ 20 日均量 × 0.8；20 日平均成交额 ≥ 1 亿元；
  ⑤ 买点（二者命中其一，entry_mode 控制）——突破：收盘 > Pivot（近 45 日
     最高，不含当日）且当日量 ≥ 20 日均量 × 1.5；回踩：10 日内曾放量突破
     Pivot，当日收盘仍 ≥ Pivot（前高转支撑不破）且收盘位于 MA20 带 ±2% 内、
     当日量 ≤ 突破日量 × 0.8、收盘 > MA50；
  ⑥ 非 ST/*ST（skip_st）、信号日处于回测区间内、命中全部附加市场过滤条件
    （`conditions`，如价格区间）、固定本金按次日开盘价能买入至少 1 手；
  低于任一要求不触发买入。次日开盘高开超过 `max_chase_pct`（默认 5%）放弃。
  满足要求的信号也不保证成交：当日资金或持仓不足时，低分信号被跳过（整笔作废）。
- 数据要求：MA200 与 250 日高点需要信号日前约一年的历史数据，回测/预测的
  `warmup` 应 ≥ 250，否则区间前期指标为 NaN、无信号。

### 买入量
固定本金仓位（`lib/position.py` 的 `FixedCapitalPosition`）：
买入股数 = `capital` // 次日开盘价，向下取整到整手（`lot_size`，默认 100 股/手）；
不足 1 手放弃本次买入。本金与手数可在配置段 `FixedCapitalPosition` 调整。
（原文按"单笔风险 = 账户 × ~0.35%，股数 = 风险额 ÷ (买入价 − 止损价)"倒推仓位，
固定本金模型无法表达，以统一约定替代——止损越宽的基底同样买固定股数，风险敞口
相对更大，属已知近似。）

## 卖出

### 卖出条件
持仓次日起每日收盘依次检查（A 股 T+1：买入当日不可卖出），满足任一条件即
次日开盘卖出：
- **止损（形态失效）**：收盘跌破信号日算出的止损价——止损价 = max(买入价 ×
  (1 − `stop_loss_pct`)，多重优势区下沿 × (1 − `stop_buffer_pct`))，二者取更近
  （更高）者：`stop_loss_pct`=0.05（原文止损幅度 3%~5% 的上限），
  `stop_buffer_pct`=0.02（止损放在支撑区下方约 2%，对应"止损设在整理区间最低
  点/支撑位下方"）。突破后已远离支撑区的持仓按 5% 固定止损兜底
- **趁弱卖（跌破持仓均线带）**：收盘 < MA`exit_ma_window` × (1 − `exit_ma_buffer_pct`)
  （`exit_ma_window`=10、`exit_ma_buffer_pct`=0.01，原文规则：纯动量股跌破
  10/20 日均线（留少量缓冲）即离场；A 股日线近似取 10 日线——更快锁定趋势破坏）
- **趁强卖（固定止盈）**：收盘 ≥ 买入价 × (1 + `take_profit_pct`)（默认 0.20，
  原文"阻力位或风险收益比 2~2.5 倍分批止盈"的机械近似；对应 Minervini 20~25%
  止盈纪律。原版为分批卖出，本仓位的全仓模型一次卖完）
- **时间止损**：持仓满 `max_hold_days` 天（默认 60 个交易日，约 3 个月——原文
  为波段~中线持仓，数周到数月）
- 回测区间结束：日期到达 `end_time` 或最后一条数据，按当日收盘强制平仓
- 「趋势持有/零成本减仓」需人工判断股票类型（护城河/行业空间），非机械规则，
  不在实现内（见策略描述）。

### 卖出量
全部卖出（卖出数量 = 买入数量，见 `FixedCapitalPosition.sell_amount`）。
